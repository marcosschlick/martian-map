# PALETTE.md

- `#020617` — Primary HUD background (`slate-950`, use `/90` opacity with backdrop blur in standard mode, solid in Pressurized Glove Mode)
- `#0F172A` — Secondary surface / cards / inactive buttons (`slate-900`)
- `#1E293B` — Subtle HUD borders and dividers (`slate-800`)
- `#F8FAFC` — Primary text and telemetry values (`slate-50`)
- `#94A3B8` — Secondary labels and units (`slate-400`)
- `#06B6D4` — Primary accent, active controls, and Habitat marker (`cyan-500`)
- `#10B981` — Safe autonomy radius and valid EVA routes (`emerald-500`)
- `#F59E0B` — Moderate solar radiation warning or low reserve < 30% (`amber-500`)
- `#EF4444` — Critical danger, Point of No Return breach, or severe solar storm (`red-500`)
- `#22D3EE` / `#FACC15` — High-contrast active highlights for Pressurized Glove Mode (`cyan-400` / `yellow-400`)
